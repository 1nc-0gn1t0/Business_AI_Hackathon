# Изолированное обновление контейнеров

Для нового локального запуска используйте новое Compose project name и новый volume по [LOCAL_SETUP](LOCAL_SETUP.md). Нельзя направлять новый образ на старый непроверенный PGDATA. Защитный entrypoint намеренно отказывает такому запуску; не обходите его удалением файлов.

Для переноса заполненной установки: остановите записи, создайте шифрованный backup по [BACKUP_RESTORE](BACKUP_RESTORE.md), восстановите в отдельный новый volume, примените миграции и проверьте владельцев, согласия, counts/hashes и байты исторических PDF/JSON. Сохраните старый volume и digest образов до завершения проверки. Не выполняйте in-place обновление версии PostgreSQL и не удаляйте исходные данные.

Инструменты `scripts/restore_container_upgrade.py` и `scripts/check_postgis_guard.ps1` сохранены; перед выполнением изучите их параметры через `--help`/исходный код. [Ограничения безопасности](SECURITY_AND_LIMITATIONS.md).
