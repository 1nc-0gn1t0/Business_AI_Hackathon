# Безопасность и ограничения

Business AI подготовлен для локального ознакомления жюри. Оснований называть приложение production-ready нет.

## Данные и модель

LLM работает локально через Ollama; облачный inference по умолчанию не используется. Модель может ошибаться, возвращать некорректные структуры и медленно отвечать. Подтверждение значения не превращает гипотезу в измерение рынка. Не отправляйте чувствительные данные в публично доступную установку.

OSM отражает картированные объекты в ограниченном bbox и периоде; отсутствие POI не означает отсутствие бизнеса. Покрытие пешей сети и POI может различаться. Полного покрытия городов и достоверных потоков покупателей нет. Синтетический набор кофейни маркирован `synthetic`, включается явно и не является рыночной статистикой. GHSL и licensed-источники не подключены.

## Банки и финансы

Каталог банковских продуктов демонстрационный. Реальной интеграции с ВТБ или другими банковскими системами, банковского скоринга, одобрения кредита и реальной отправки заявок нет. Legacy-квитанции являются mock; для новых отраслей mock-заявки недоступны.

Финансовые результаты — сценарная арифметика по введённым/проверенным допущениям, а не прогноз доходности. Равные границы могут дать одинаковые сценарии. Общая отрасль требует согласованных единиц; недостающие методы остаются partial. JSON новых отраслей поддерживается, PDF — только в legacy-пути. Живые метаданные покрытия и текущий банковский подбор не являются immutable рыночным snapshot.

## Доступ и эксплуатация

Гостевой bearer-токен связывает диалог с владельцем; полноценные аккаунты, срок жизни гостевых сессий, автоматические retention/удаление и production-политики хранения не реализованы. Потеря токена ограничивает восстановление доступа, его утечка опасна. Не публикуйте БД, diagnostics/operator-токены и резервные копии. Диагностический токен не заменяет аутентификацию публичного пилота. API имеет локальные лимиты, но они не заменяют распределённую защиту от DoS и контроль общего объёма накопленных данных.

Compose привязывает API/web к loopback, БД не имеет host-порта. Контейнеры ограничивают capabilities; API/БД работают без root. Это снижает поверхность атаки, но не является доказательством отсутствия уязвимостей. Ollama должен оставаться в доверенной локальной сети. Перевод в публичный сервис потребует отдельной проверки аутентификации, TLS, квот, резервирования и доступа операторов.

## Контейнеры и зависимости

В исходной проверке образов от 27.10.2026 после hardening оставались 3 Critical и 36 High уникальных advisory ID в объединённом наборе образов; API отдельно имел 8 High, БД — 3 Critical/36 High. Это исторические данные, а не повторное сканирование этой публикации и не доказательство эксплуатации. Затронуты native-библиотеки XML, GDAL/TIFF, клиент MariaDB, PostGIS и системные пакеты. Отсутствие отдельных прикладных маршрутов не исключает SQL/native-поверхность. Релизный security baseline остаётся открытым; исключения по всем рискам не приняты.

CI проверяет известные исправимые Critical/High и аудиты Python/npm. Успешный scoped gate не означает отсутствия неисправленных рисков. База advisory меняется; результаты повторных проверок и их фактический объём приведены в [Публичное техническое описание](SECURITY_AND_LIMITATIONS.md).
