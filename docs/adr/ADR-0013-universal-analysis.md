# ADR-0013: отраслевой анализ

Принято: общий отраслевой профиль и план применимых этапов сосуществуют с legacy-путём кофейни. Незнакомая идея не превращается автоматически в кофейню; недоступные методы и данные дают partial-результат.

Профиль, происхождение значений и подтверждение контролирует backend. Qwen предлагает данные через ограниченный структурированный протокол; модель не получает права на произвольную загрузку источников или исполнение формул. Registry и acquisition имеют отдельные операторские разрешения.

Финансовые входы связаны с ревизиями профиля, проверяются владельцем и сохраняются отдельно от immutable results. Что-либо вычислять после устаревшей ревизии без проверки нельзя. Receipts и fencing определяют завершение/отмену действия; inference выполняется вне долгой транзакции БД.

Интегрированный результат объединяет финансовый snapshot и текущую оценку покрытия; `assessed_at` не обозначает дату измерения рынка. Банковский подбор информационный. Legacy-отчёты сохраняют прежний формат; новые отрасли экспортируют JSON.
