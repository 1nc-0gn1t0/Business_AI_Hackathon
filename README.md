# Business AI

Business AI (Sab0tage) — локальный AI-ассистент для анализа бизнес-идей, геолокаций и финансовых сценариев с информационным подбором банковских сервисов.

Предпринимателю трудно сопоставить идею, расположение, расходы и потребности в финансировании. Business AI объединяет эти шаги в диалоге, показывает происхождение данных и явно отмечает пробелы. Предприниматель получает проверяемые предположения и расчёты; банк — прототип сопровождения клиента от идеи к релевантным сервисам. Подключения к банковским системам ВТБ нет.

## Возможности

- Диалог с локальной Qwen, уточнение и подтверждение бизнес-профиля, помощник Vi.
- Отраслевые профили кофейни, автосервиса, онлайн-школы и общий сценарий для других услуг.
- Для поддерживаемого геосценария: OSM, зоны-кандидаты, пешая доступность и ранжирование с учётом покрытия.
- Финансовые гипотезы с ручной проверкой, три сценария, безубыточность, чувствительность и what-if.
- Информационный подбор демонстрационных банковских продуктов, раздельные согласия; mock-заявки в legacy-сценарии.
- Восстановление состояния диалога и расчётов; JSON результатов. PDF доступен для legacy-отчётов, для новых отраслей — JSON.

## Архитектура и стек

React 19 / TypeScript / Vite / MapLibre → FastAPI (Python 3.12, модульный монолит) → PostgreSQL 17 / PostGIS 3.6. SQLAlchemy и Alembic отвечают за хранение и миграции. Ollama запускает Qwen локально: модель предлагает структурированные данные, а сервер валидирует их и считает финансовые результаты детерминированно. Дополнительный worker загрузки данных включается оператором отдельно.

Подробнее: [архитектура](docs/ARCHITECTURE.md), [продукт](docs/PRODUCT_OVERVIEW.md).

## Локальный запуск

Нужны Docker с Compose v2 и работающий Ollama. Из корня клона в PowerShell:

```powershell
Copy-Item .env.example .env
ollama pull qwen3:4b-instruct-2507-q4_K_M
docker compose -p business-ai-hackathon up --build --detach --wait
```

Если сервер Ollama ещё не запущен, выполните `ollama serve` в отдельном терминале. Загрузка модели и зависимостей требует сети, диска и времени. Интерфейс: http://127.0.0.1:5173; API: http://127.0.0.1:8000/docs. Для актуального отраслевого пути включите в `.env` `BA_INDUSTRY_ENABLED=1` и `BA_FINANCE_V2_ENABLED=1` перед запуском. Пустая БД не содержит OSM: отсутствие геоданных отображается как ограничение, а не заменяется выдуманным анализом.

Полная инструкция, отдельный запуск API/web, миграции и остановка: [LOCAL_SETUP](docs/LOCAL_SETUP.md).

## Статус и ограничения

Хакатонный продукт для локального ознакомления. Не production-ready и не банковский скоринг. Данные OSM неполны; синтетика маркирована отдельно. Расчёты зависят от подтверждённых предположений и не являются инвестиционной рекомендацией. GHSL и лицензируемые источники представлены контрактами без подключённых наборов. В контейнерных зависимостях остаются известные существенные риски; подробности в документе безопасности.

Публичный снимок исходного `main`: `da535da7730fc236a9b2586345a74a24de1b344a`. История разработки в этот репозиторий не переносилась.
